# Muzahidul Islam — Portfolio

A responsive personal portfolio website built with React + Vite.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for submission

```bash
npm run build
```

## What to edit before submission

Open `src/main.jsx` and replace:
- `your.email@example.com`
- GitHub and LinkedIn links
- Sample project descriptions with your real projects
- `MI` in the profile circle with a photo later if desired

The site is already responsive for mobile, tablet, and desktop.
